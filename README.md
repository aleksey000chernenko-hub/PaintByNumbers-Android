# Картина по номерам — Android MVP 2.0

Приложение на Kotlin + Jetpack Compose, которое преобразует фотографию в комплект для картины по номерам.

## Что умеет
- выбрать любое фото из памяти телефона;
- сократить изображение до 12–36 основных цветов методом k-means;
- объединить слишком мелкие цветовые области;
- создать цветной эталон;
- создать белый контурный макет с номерами областей;
- создать лист палитры: номер, HEX и RGB каждого цвета;
- сохранить сразу 3 PNG-файла в `Pictures/PaintByNumbers`.

## Как собрать APK
GitHub Actions автоматически собирает debug APK при каждом push в main.
